# Clash 配置

本仓库提供一份 [`config.yaml`](./config.yaml) 作为 Clash（兼容 Mihomo/Clash Meta）的配置文件模板。

## 使用方法

1. 下载 `config.yaml` 到本地，或在 Clash 客户端中直接导入该文件。
2. 打开文件，将 `proxies` 部分的示例节点替换为你自己的真实节点信息（服务器地址、端口、密码/UUID 等）。
   如果你使用订阅链接，可以直接在客户端中导入订阅，无需手动填写节点。
3. 根据需要调整 `proxy-groups`（节点分组）与 `rules`（分流规则），例如新增你常用的域名直连规则。
4. 将配置文件导入 Clash 客户端（Clash for Windows/Android、ClashX、Stash、Mihomo 等）后即可使用。

配置文件中包含以下内容：

- **DNS**：使用 DoH 服务器并对国内域名优化解析。
- **代理分组**：提供「节点选择」「自动选择（测速）」「全球直连」「广告拦截」「漏网之鱼」等常用分组。
- **分流规则**：按广告拦截、国内域名/IP 直连、局域网直连、其余流量走代理的顺序匹配。
