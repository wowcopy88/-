# 俄罗斯方块

一个纯 HTML / CSS / JavaScript 编写的单页俄罗斯方块小游戏。

## 开始游玩

直接用浏览器打开 `index.html`，或在仓库根目录启动一个静态服务器后访问页面。

例如：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 操作方式

- `←` / `→`：左右移动
- `↑`：旋转
- `↓`：加速下落
- `空格`：一键到底
- `P`：暂停 / 继续
- `R`：重新开始

页面底部也提供了触屏按钮，适合手机操作。

## 音效与背景音乐

- 点击页面右上角的“声音”按钮可开启或关闭背景音乐与操作音效。
- 出于浏览器自动播放限制，通常需要先点击一次按钮或操作一次游戏，声音才会开始播放。
